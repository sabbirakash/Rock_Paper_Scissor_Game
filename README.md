## 📌 Project Overview

This project is a simple yet interactive implementation of the classic **Rock Paper Scissor** game. The application allows the player to compete against a computer opponent whose move is generated randomly.

The game is developed using **Python** and deployed with **Streamlit**, providing a responsive web-based interface without requiring any frontend framework.

This project is ideal for beginners who want to understand:

- Python programming fundamentals
- Conditional statements
- Dictionary mapping
- Random number generation
- Game logic implementation
- Streamlit web application development

## ⚙️ Game Logic

### Step 1

The player selects one of:

- 🪨 Rock
- 📄 Paper
- ✂️ Scissor

---

### Step 2

The computer randomly chooses one option.

---

### Step 3

Both choices are compared using predefined game rules.

---

### Step 4

The application immediately displays whether the player:

- ✅ Wins
- ❌ Loses
- 🤝 Draws

## 💻 Installation

Clone the repository

```bash
git clone https://github.com/sabbirakash/Rock_Paper_Scissor_Game.git
```

Go to the project directory

```bash
cd Rock_Paper_Scissor_Game
```

Install dependencies

```bash
pip install streamlit
```

Run the application

```bash
streamlit run Rock_Paper_Scissor_Game_Deploy.ipynb
```

---

## 🎮 How to Play

1. Launch the Streamlit application.
2. Choose Rock, Paper, or Scissor.
3. Click the **Play!** button.
4. The computer generates a random move.
5. The result is displayed instantly.
